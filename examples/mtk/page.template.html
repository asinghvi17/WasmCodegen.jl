A ModelingToolkit model, solved in your browser

A mass on a spring with damping and a periodic driving force. ModelingToolkit simplified the model and generated its code ahead of time; every change here re-solves it with OrdinaryDiffEq's Tsit5 over t ∈ [0, 30] s in WebAssembly, and reads the energy back through the model's own observed function.

E    ~ m*v^2/2 + k*x^2/2

Symbolic at build time

ModelingToolkit runs when the module is built: mtkcompile eliminates the algebraic equations, and with eval_expression = true it generates the right-hand side and the observed functions as ordinary Julia code, which WasmCodegen compiles with trim = :safe.

Objects in the module

The integrator is built with init when the module is compiled and serialized into it: __OBJECTS__ Julia objects, its MTKParameters included. The page calls MTK's parameter setter (setp), then reinit! and solve!.
